# Touche brain

Private working memory for Touche: ethos, follow-ups, gotchas, threads, infrastructure, people, session notes. Claude reads it at the start of every session in the code repo, so context never has to be rebuilt.

It lives **outside** the code repo on purpose: the code repo may be shared with a team or contractors; the brain stays with the owner. Same system as `authority-os-brain` (CitationOS).
